# L&T Realty Price Predictor

🚀 **Live Web Application:** https://lt-realty-price-predictor-zmsb9siuzmhhwjnrjgmoll.streamlit.app/Analysis_App

## Overview
An interactive Machine Learning web application built with Streamlit to estimate and analyze real estate property prices.

## Features
- **Price Predictor:** Instant property valuation using ML models.
- **Analytics Dashboard:** Geographical and data insights with interactive charts.
- **Apartment Recommender:** Recommendations based on property characteristics.

## Tech Stack
- **Frontend / Framework:** Streamlit
- **ML & Data Processing:** Scikit-Learn, XGBoost, Pandas, NumPy
- **Visualization:** Plotly, Matplotlib, Seaborn, WordCloud
